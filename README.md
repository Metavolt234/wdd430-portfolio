# Tumwesige Nelson Portfolio

This is a portfolio website built with Next.js and Tailwind CSS. It includes a home page, an about page, reusable UI components, and a simple API route.

## Local Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.
